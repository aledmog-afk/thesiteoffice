Built for humans and for AI agents

The checklist behind this tool is not hidden inside a black box. It's published as an open, versioned JSON ruleset with plain-English guidance and a legal/HSE reference for every item — so a developer, an AI coding agent, or an LLM-based site-management assistant can run the same audit programmatically instead of guessing what "good" looks like.

fetch('https://thesiteoffice.uk/compliance-rules.json')
  .then(r => r.json())
  .then(rules => {
    // rules.structuralChecks / rules.hazardChecks / rules.vagueLanguageFlags
    // each item has: id, weight, patterns, guidance, reference
    console.log(rules.structuralChecks[0]);
  });

Reference scoring implementation: tools/rams-auditor/engine.js (plain JS, no dependencies, MIT-style reuse). Ruleset license: CC-BY-4.0 — reuse it, just credit The Site Office.

This tool is a screening aid that checks for the presence of required sections, hazard-specific controls and clear wording using pattern matching. It is not a substitute for sign-off by a competent person, a principal contractor's review, or professional/legal advice, and a high score does not guarantee legal compliance. Always have RAMS reviewed by a competent person before work starts on site.
